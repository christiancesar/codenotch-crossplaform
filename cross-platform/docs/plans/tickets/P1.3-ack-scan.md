# Ticket P1.3 — Wire `ack_scan` to Linux focus detection

- Phase: **1** (unblocks real desktop use) · Depends on: **P1.2 (must land first)** · Lane:
  main.rs
- Verifies on: real X11 (`DISPLAY=:1`, GNOME/Mutter, this host).

## Goal

"Seen-clears-it": on Windows, `ack_scan` (`main.rs` ≈1050) checks whether the foreground window
belongs to the process chain of a `done` session, and if so clears that session's `done` state —
the idea is that *looking at* the terminal that finished a turn counts as acknowledging it, no
click required. On Linux `ack_scan` is a stub that always returns `false`, so a `done` session on
Linux **never clears itself** — it stays in the notch until it hits the 24h stale sweep.

## Scope (exactly this)

Port the Windows `ack_scan` logic to Linux using the **foreground window** instead of Windows'
`focus::fg_pid()` equivalent:

1. Get the currently active window's pid via EWMH (`_NET_ACTIVE_WINDOW` on the root window, then
   `_NET_WM_PID` on that window) — this is the read-only counterpart to the *activate* call P1.2
   added, so if P1.2 already exposed a "pid of the active window" helper, call it; otherwise add
   one alongside it in `focus.rs` (small, same file P1.2 touched, so land after P1.2 to avoid
   fighting its diff).
2. Mirror the Windows branch exactly: if no session has `done` state, short-circuit `false`; else
   match the active window's pid against each done session's process chain
   (`focus::pid_hits_chain`) the same way Windows does, and call `store.ack_done(...)`.
