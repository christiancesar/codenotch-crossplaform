# Phase 0: compatibility gate

Phase 0 of `cross-platform/docs/specs/2026-09-15-cross-platform-architecture-spec.md`.
Nothing on `feat/codenotch-next` merges into `development` until every item here holds
for the new app in `backend/` + `frontend/`.

## Golden fixtures

`backend/tests/fixtures/persisted/`:

| Directory | Content |
| --- | --- |
| `v0.3.1/` | The maintainer's real files from `~/.config/codenotch/` at v0.3.1 (`config.json`, `usage.json`, `codex.json`, `cursor.json`, `antigravity.json`, `opencode.json`). They hold no account data: ids, labels, fractions and epoch-ms timestamps only. |
| `legacy/` | Hand-written shapes `config::load()` still has to handle. |
| `expected/` | What v0.3.1's `config::load()` returns for each config fixture, generated by running that function on it. The new loader must produce the same values. |

Config cases:

| Fixture | What it exercises | Expected after load |
| --- | --- | --- |
| `v0.3.1/config.json` | Current format, every key present | Identical round trip |
| `legacy/config-pre-slots.json` | No `tray_mode`, no `*_slots`, only `tray_providers` / `notch_providers` | `tray_mode = "off"` (an existing install keeps the plain mark), each provider becomes a slot with `window = ""` |
| `legacy/config-port-only.json` | Minimal file | Defaults everywhere except `port = 48777`; `tray_mode = "off"`; tray slots from the default `["claude", "codex"]`; `notch_slots` empty (all providers) |
| `legacy/config-both-hidden.json` | `notch_visible` and `tray_visible` both false | `tray_visible` forced back to true |
| `legacy/config-scale-out-of-range.json` | `scale = 3.5` | Clamped to `1.0`; `notch_y = 0.1` kept |
| `legacy/config-unknown-keys.json` | A key this version does not know | Known values kept (`lang = "ja"`). See finding 2 |
| `legacy/config-truncated.json` | A file cut mid-write | Must be quarantined, never overwritten. See finding 1 |

Snapshot rule (all providers): a snapshot with at least one window loads with
`status = "stale"`; `backoff_until` survives. Antigravity loads its snapshot only when the
note starts with `via Antigravity CLI` and recomputes `status` from `fetched_at` against
the CLI TTL. The Claude snapshot file is `usage.json`, not `claude.json`.

## Findings in v0.3.1 the new loader must not repeat

1. **Unreadable config is overwritten.** `config::load()` falls back to defaults on any
   parse error and `setup()` saves right after, so `config-truncated.json` would be
   replaced by defaults. New behaviour: rename to `config.json.unreadable-<ts>`, log it,
   run on defaults, write only when the user changes something.
2. **Unknown keys are dropped on save.** `Config` has no catch-all field, so a key a newer
   build wrote disappears the first time an older build saves. New behaviour: keep
   unknown top-level keys (`#[serde(flatten)] extra: Map<String, Value>` in the stored DTO).
3. **`codex.json` in the `needsAuth` state has no `windows` key.** `UsageSnapshot.windows`
   has no `#[serde(default)]`, so v0.3.1 fails to parse that real file and silently starts
   from an empty snapshot, losing the note and status. New behaviour: missing `windows`
   reads as an empty list; status and note survive.

## Frozen contracts

These do not change in the rebuild:

- Binary names `codenotch` and `codenotch-hook`. The hook launches `codenotch` from its own
  directory; `~/.claude/settings.json` entries are recognized by the `codenotch-hook` name.
- Config directory `dirs::config_dir()/codenotch/` and the file names in it: `config.json`,
  `usage.json`, `codex.json`, `cursor.json`, `antigravity.json`, `opencode.json`,
  `glyphs/`, `quota-work/`, `run.log`, `install.log`, `doctor.log`, `watch.log`,
  `user-quit`.
- Top-level `"port"` key in `config.json` (the hook scans the text for it), default 48666.
- Hook route `POST http://127.0.0.1:<port>/event?e=<event>&ppid=<pid>`, JSON body from
  Claude Code; events `session_start`, `running`, `attention`, `done`, `session_end`.
- `user-quit` marker: written by tray Quit, removed on launch, honoured by the hook.
- Tauri `identifier` `com.immidi.codenotch` and `productName` `Codenotch` (single-instance
  and installers derive the app identity from them).
- Autostart: `Codenotch` Run value on Windows, `--silent` flag.
- CLI: `install-hooks`, `uninstall-hooks`, `autostart on|off`, `doctor [deep]`.
- Linux: `GDK_BACKEND=x11` forced when `DISPLAY` exists, `CODENOTCH_WAYLAND=1` opt-out.

## Parity checklist (v0.3.1)

Each line is checked by hand on Linux (Ubuntu 26.04, GNOME 50, XWayland) and on Windows
before the merge.

Notch
- [ ] Pinned to the right edge of the primary monitor at the saved `notch_y`
- [ ] Collapsed nub on Linux; pill on Windows
- [ ] Hover over the pill expands the card; leaving collapses it after ~250 ms
- [ ] Clicks outside the pill and card go to the window behind
- [ ] Vertical drag moves the notch and persists `notch_y`
- [ ] Scale slider in the card resizes the pill live and persists `scale`
- [ ] Rings per `notch_slots`, fullest window when `window` is empty
- [ ] Working state spinner while a Claude session runs; attention and done states
- [ ] Click on a session focuses its terminal; dismiss removes it
- [ ] Stale readings shown dimmed after a restart
- [ ] Focus or workspace change forces the card closed

Tray
- [ ] Modes `off`, `numbers`, `bars` per `tray_slots`
- [ ] Menu: Settings, Refresh, Quit
- [ ] Quit stops hook relaunches until the next manual start

Settings window (panes)
- [ ] Taskbar icon: mode, slot chips and picker, live preview
- [ ] Notch: ring slot list, size slider
- [ ] Behaviour: autostart, show notch, show tray icon, language (auto, en, zh, ja, ko)
- [ ] Claude Code: hooks switch matches `~/.claude/settings.json`
- [ ] About: version, open data folder, reset notch position
- [ ] Closing the window hides it; it reopens from the tray
- [ ] Notch and tray cannot both be hidden

Providers
- [ ] Claude, Codex, Cursor, Antigravity (CLI and language server), OpenCode readings
- [ ] `needsAuth`, `backoff`, `error` states rendered, never a guessed number
- [ ] Claude 429 backoff persisted across restarts

System
- [ ] Hooks: every Claude Code event reaches the app; app relaunched when it crashed
- [ ] Autostart on and off
- [ ] `codenotch doctor` and `doctor deep` write `doctor.log`
- [ ] Installing over v0.3.1 keeps `config.json` and snapshots (fixtures above pass)
